Before the workshop

  1. Install the GitHub Copilot app and sign in with a GitHub account that has app access. VS Code alone does not provide these app labs.
  2. Install Git and Node.js 22.x. The exact Node version used in CI is in .nvmrc.
  3. Clone the starter repository (or your own fork if you want to open a practice PR). Run npm ci, npm test, and npm start from the clone.
  4. Open the local planner after starting it, or try the hosted starter planner without installing Node.
